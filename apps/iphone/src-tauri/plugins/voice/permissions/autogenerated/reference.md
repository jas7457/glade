## Default Permission

Everything conversation mode needs: permissions, voices, the audio session, listening, speaking and cues.

#### This default permission set includes the following:

- `allow-is-available`
- `allow-get-permissions`
- `allow-request-permissions`
- `allow-request-personal-voice`
- `allow-list-voices`
- `allow-start-session`
- `allow-end-session`
- `allow-start-listening`
- `allow-stop-listening`
- `allow-speak`
- `allow-stop-speaking`
- `allow-play-cue`
