Every agent in one window.

pi, Claude Code and Codex live in the same sidebar, and every chat remembers which one it runs on. Glade drives the command-line tools you already have, with your own logins, so their models, thinking levels, permission modes and slash commands become native controls.

Each agent gets its own page in Settings: its default model and thinking level, which models you see, and its version, with a one-click update.

Hand off the work. Keep talking.

When an agent delegates, each sub-agent gets a name, a colour and its own tab. Their cards show what every one of them is doing right now, and their reports land back in the chat that started them.

Give sub-agents a cheaper model if you like. When Claude Code or Codex starts its own sub-agents, they show up the same way.

While an agent works, ↩ steers it, ⌘↩ sends a follow-up for when it's done, and ⌥↩ asks a side question it never sees. Hold ⌘ or ⌥ and the Send button shows which one you'll get.

Your Mac does the work. Your iPhone keeps up.

The iPhone app pairs with your Macs and shows every chat from all of them in one list. Read along, steer, answer a permission card, start a new chat: the agents keep running on the Mac whose files they are. Macs can use each other the same way, so a MacBook can work in the projects on a Mac Studio.

Remote access runs over Tailscale on your private tailnet, over HTTPS and never on the public internet. Every new device needs your Allow, and you can revoke one at any time.

Local models, on your terms.

Glade works with llama.cpp's llama-server on your Mac. See what's loaded, how much memory it takes and which chats use it, and load or unload models from the Mac, another Mac or your phone. Loaded models appear in pi's model picker.

Glade never downloads or unloads a model by itself.

A worktree per chat. A diff before you commit.

Start a chat in its own git worktree and branch, and bring your uncommitted changes along if you want. The changes panel lists every changed file with its diff: discard what you don't want and commit with a generated message.

Deleting a worktree chat asks whether to keep its branch, merge it or discard it.

Find anything you've talked about.

⌘K jumps to any chat, project or action, and searches inside every conversation, opening right at the matching message. Can't remember the words? Describe the chat and a fast model picks it out.

Bookmark the replies worth keeping (⌘D). They get a ribbon, and you find them again from the chat header or ⌘K, or reference one in your next message.

A terminal beside the chat.

Press ⌃` for a shell in the chat's folder, in a tab next to your conversations. It runs on the chat's Mac, keeps its output when you switch tabs, and asks before closing something that's still running.

Or type !command in the message box: it runs in the chat's folder and the agent sees the output.

Talk it through.

Voice mode on the iPhone listens, sends when you pause, and reads the reply aloud as it's written, highlighting each word. Talk over it to interrupt, and answer the agent's questions by voice.

Minimize it and the highlight follows along in the chat while it keeps listening. Speech recognition and voices are Apple's own, on the device. No extra accounts or keys.

Build it yourself.

Glade isn't a signed download yet. Clone the repository and build the Mac app; it takes a few minutes the first time.

You'll need

  • A Mac with macOS
  • Node.js 22.13 or newer
  • pnpm (corepack enable sets it up)
  • Rust and the Xcode Command Line Tools, for the Mac app
  • At least one agent, installed and signed in: pi, Claude Code or Codex

Optional

  • Tailscale, to use Glade from your other Macs and your iPhone
  • llama.cpp's llama-server, for local models
  • Xcode and an Apple ID, to put the iPhone app on your phone
Terminal 
git clone https://github.com/jas7457/glade.git
cd glade
pnpm install
pnpm tauri:install

pnpm tauri:install builds Glade and puts it in your Applications folder. To update later, use Update Now in Settings → General, or pull and run the last two commands again.
